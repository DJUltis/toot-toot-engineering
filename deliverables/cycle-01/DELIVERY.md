# DELIVERY (cycle-01)

## What shipped
- K10 Arduino TTDB navigator sketch.
- Compact Dice TTDB sample for micro SD.
- Usage notes and review.

## Files
- `deliverables/cycle-01/k10_ttdb_navigator.ino`
- `deliverables/cycle-01/assets/ttdb_dice_k10.md`
- `deliverables/cycle-01/SOLUTION.md`
- `deliverables/cycle-01/REVIEW.md`

## How to run
1. Copy `deliverables/cycle-01/assets/ttdb_dice_k10.md` to the SD root as `ttdb_dice_k10.md`.
2. Upload `deliverables/cycle-01/k10_ttdb_navigator.ino` to the Unihiker K10.
3. Use buttons A/B to navigate and A+B to toggle list/detail.

## Export notes
- The sketch expects the TTDB path `/ttdb_dice_k10.md` on the SD card.
