# STORYTELLER (cycle-02)

## Narrative focus
The configurator is the “atelier” for the K10 TTDB navigator: a quiet workshop where the globe’s colors, labels, and rhythms are tuned before deployment to the device.

## UX beats
- **Welcome:** A clear, compact form of settings with immediate visual feedback.
- **Preview:** Side-by-side list/detail mockups that update as colors or layout values change.
- **Confidence:** One-click export with a readable JSON format.

## Visual tone
- Keep the K10 palette grounded in the dark, low-contrast theme from `ttdb_navigator.py`.
- Use warm highlights for selection and a cool accent for the active node.

## Interaction mapping
- Left pane: settings and presets.
- Right pane: live previews (list + detail).
- Bottom: export status and file path.
