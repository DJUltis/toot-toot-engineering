# Toot-Toot Engineering Prompt

A complete Toot Toot Network, one device per cycle. The first device for the first cycle will be a Unihiker K10 running Arduino. The second will be a Heltec LoRa 32 for cycle 2. Later devices and cycles will be decided later.
Refer to DFRobot_UNik10.ino as sample code verified to have worked on the target hardware.
Make use of the K10 micro SD card to store an adapted ttdb. Begin with an adapted copy of Dice.md as a sample. Leverage as much of the ttdb_navigator.py behavior and styling as possible, using the k10 buttons and tilt and any additional k10 capabilities that could apply.

## deliverables
a new Arduino sketch, ready to upload to the k10
