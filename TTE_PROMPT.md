# TTDB Dungeon Crawler for the K10 

Create a complete K10 Dungeon Crawling game making creative use of the K10 capabilities (see https://www.unihiker.com/wiki/K10/) and simple tap-to-choose-the-path UI.

---

## High-Level Goal
Build a UNIHIKER K10 touchscreen dungeon crawler where:

**The user enters a text-based dungeon crawler game where they are taken on a fun story with choices that take the story down multiple paths to good or bad endings, which are always silly. The story should open at the entrance to a cave with a little campfire inside. The story should lead to one path that step by step accurately and helpfully explains mmpdb usage and potential applications. One path should lead to a cosmic dimension of eyeball nodes casting longing gazes at one another. Another path should lead the adventurer to the discovery that they are actually a food, in the process of being eaten and digested.**

The application should be deployed with a dedicated, populated mmpdb and should refer to TTDB-RFC documents, "standards" documents, and tte_monitor.py for patterns, standards and usage examples to follow.

---


## Deliverables
Produce a repo-style project with:
1. `TTDB_README.md` that includes:
   - A brief but dramatic introduction
   - Step-by-step device installation and configuration
   - folder and file structure of the installation bundle
   - step-by-step how to run on the device

2. An installation bundle containing 
   - a purpose-built mmpdb
   -  python files
   - anything else needed
